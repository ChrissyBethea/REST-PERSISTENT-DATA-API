Module 4 Assignment 2 – Reflection
For this assignment, I created a RESTful API using Python and Flask to store clinical patient records in two different locations. I started by setting up the database connection, creating the patient model, and using Pydantic to validate the information. I also added three additional fields: blood type, allergies, and emergency contact.
After creating the API endpoints, I tested adding a fictional patient record and retrieving it through my browser. I then checked the SQLite database and JSON Lines file to verify that the information was being stored. One challenge I experienced was getting the POST request to work correctly in PowerShell. After adjusting the command, I was able to successfully create the record.
What surprised me most was how one API request could save information in two different formats. This assignment helped me better understand data persistence, database models, JSON validation, and how RESTful APIs communicate with storage systems. I would like to learn more about managing larger databases and protecting sensitive patient information.
